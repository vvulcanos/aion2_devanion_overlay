# Daevanion Overlay

아이온2 데바니온 플래너에서 짠 빌드를 게임의 데바니온 화면 위에 겹쳐 보며 찍을 수 있는 Windows용 앱입니다. 앱 안에 플래너도 함께 들어 있습니다.

이 저장소에는 설치 파일만 올라옵니다.

## 내려받기

**[Daevanion-Overlay-Setup.exe 내려받기](https://github.com/vvulcanos/aion2_devanion_overlay/releases/latest/download/Daevanion-Overlay-Setup.exe)** (최신 버전)

코드 서명이 없어서 처음 실행할 때 Windows SmartScreen 경고가 뜹니다. 버전별 파일과 SHA-256 값은 [Releases](https://github.com/vvulcanos/aion2_devanion_overlay/releases)에 있습니다.

## 쓰는 법

1. 앱의 플래너에서 직업을 고르고 빌드를 짭니다. 웹 플래너에서 짠 빌드는 **게임 오버레이 → 앱에서 열기**로 가져옵니다.
2. **게임 오버레이** 버튼으로 오버레이를 켜고, 툴바에서 보드를 고릅니다.
3. 크기를 게임 화면에 맞춥니다. 슬라이더, 보드 오른쪽 아래 모서리 드래그, 해상도 프리셋(1080p, 1440p, 4K) 중 편한 것을 씁니다.
4. 툴바나 보드를 끌어서 게임의 노드판 위에 맞춥니다. 방향키로 1px씩 옮길 수 있습니다.
5. 자물쇠 버튼이나 `Ctrl+Alt+L`로 잠그면 클릭이 게임으로 통과합니다. `Ctrl+Alt+O`는 오버레이를 켜고 끕니다.

## 알아 둘 점

- 게임은 창 모드나 테두리 없는 창 모드여야 합니다.
- 해상도 프리셋은 게임 UI 크기가 기본값일 때 기준입니다. 4K 값은 1080p와 1440p에서 잰 값으로 계산한 값입니다.
- 오버레이는 별도의 창이며 게임을 읽거나 건드리지 않습니다.
- 엔씨소프트와 무관한 비공식 팬 도구입니다.
